# Photos go here

Drop a photo in with the exact name below and it appears on the site at the next build. Any ending works: .jpg, .png, .webp or .avif. Then open `src/data/media.json` and write the photo's alt text (one plain sentence describing it, for people who can't see it).

The build stops if a photo is over **600 KB**. Export at the size listed, quality about 80, and it will fit. A camera original (8 to 15 MB) is too heavy.
